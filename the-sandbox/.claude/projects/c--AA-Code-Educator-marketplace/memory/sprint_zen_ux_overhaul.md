**Zen UX Overhaul** — 22 tasks, 9 phases. Blueprint: `Blueprints/zen-ux-overhaul.md`.

**Why:** Principal UX audit found 15 friction points. Goal is cognitive load reduction + making the platform feel relaxing and delightful, not just functional.

**How to apply:** This is the active sprint. Key decisions:
- F1: Demo users reduced to 3 (admin, educator, student). Registrar role stays in type system.
- F2: Coming Soon cards moved to new "Workshop" tab in Hub (not deleted — user wants them for demo conversations about future projects). Workshop = half-built tools not ready for primetime.
- F3-F9: All friction fixes accepted (filter simplification, quick launch, course tabs 12→5, breadcrumbs, mobile nav cleanup)
- Z1-Z5: All zen pass items accepted (spacing increase, border differentiation, emoji removal from compact cards, typography to 4 tiers)
- A1-A5: All delight features accepted (empty states, Sandy personality, Jump Back In context, fade transitions)

Zero schema changes. Zero new API routes (except wiring existing `/api/recommendations`).
